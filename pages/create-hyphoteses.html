3. Avaliação de Incerteza ❔ 🔹 Muito Baixo: Quase certeza, muito conhecido.
🔹 Baixo: Pouca dúvida, bem compreendido.
🔹 Médio: Existe dúvida, mas alguns dados já ajudam.
🔹 Alto: Considerável incerteza, não temos dados sólidos.
🔹 Muito Alto: É praticamente uma aposta, não temos dados, é um completo desconhecido.

4. Avaliação de Impacto ❔ 🔸 Muito Baixo: Quase não afeta a arquitetura.
🔸 Baixo: Pequeno impacto, fácil de corrigir.
🔸 Médio: Afeta alguns componentes ou funcionalidades.
🔸 Alto: Afeta partes importantes da arquitetura.
🔸 Muito Alto: Pode comprometer completamente o sistema, inviabilizar o projeto ou gerar grandes perdas.
