
# ArchHypo  

**ArchHypo** é um plugin para **Trello**, desenvolvido para otimizar a experiência de gerenciamento de tarefas.  

## ✅ Pré-requisitos  

Antes de instalar, certifique-se de ter os seguintes requisitos atendidos:  

- **Node.js** (versão 18 ou superior)  
- **NVM** (Node Version Manager)  

## 🚀 Instalação  

Para instalar as dependências necessárias, execute:  

```sh
npm install -g netlify-cli
```

## 🔧 Executando localmente

Para instalar as dependências necessárias, execute:  

```sh
npx netlify dev
```
Isso iniciará um ambiente de desenvolvimento local para testar o plugin.
